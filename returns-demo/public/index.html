核心链路

一件事，由谁完成

消费者发起 → 客服审核 → 补充材料或寄回 → 仓库收货验货 → 客服给出结论 → 售后单关闭。

步骤岗位动作结果
1消费者选择订单商品，提交退货 / 换货申请售后单生成，进入待审核
2售后客服检查申请条件（期限、数量）同意退回 / 要求补充材料 / 拒绝
3消费者补充凭证，按指引寄回商品申请重新进入审核
4仓库人员登记收货并验货验货通过 / 异常登记
5售后客服确认模拟退款或换货补发记录退款金额 / 补发单号
6系统售后单完成时间线归档，数量释放

业务规则

必须遵守的约束

  • 只能对本人已完成的模拟订单申请售后；
  • 申请数量不能超过该商品剩余可售后数量，重复申请会被拒绝；
  • 客服同意退回后，仓库才能登记收货与验货；
  • 仓库验货不等于退款 / 换货完成，最终结论由客服给出；
  • 拒绝、补充材料、验货异常必须填写原因；
  • 每次状态变化保留操作岗位、时间与说明。
